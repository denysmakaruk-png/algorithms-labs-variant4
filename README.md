

Репозиторій містить реалізацію лабораторних робіт №1 та №2 мовою C++ (стандарт C++17) з підтримкою незалежної збірки через CMake.

- `lab1/` — **Лабораторна робота №1**: Власний шаблонний динамічний масив `CustomVector<T>`, алгоритм Штрассена для матриць довільного розміру з доповненням нулями, обернення матриць методами Гауса-Жордана та LU-розкладання, QR-алгоритм пошуку власних значень.
- `lab2/` — **Лабораторна робота №2**: Порозрядне сортування рядків за старшими розрядами (`MSD Radix Sort`) з коректною обробкою термінального символу `'\0'` та бенчмарком проти `std::sort`.


```bash
mkdir build && cd build
cmake ..
cmake --build . --config Release
```

- **Лабораторна №1:** `./lab1/lab1` (Windows: `.\lab1\Release\lab1.exe` або `.\lab1\lab1.exe`)
- **Лабораторна №2:** `./lab2/lab2` (Windows: `.\lab2\Release\lab2.exe` або `.\lab2\lab2.exe`)
